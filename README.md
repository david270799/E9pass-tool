# E9pay — документы клиентов (локально)

Десктопная программа для Windows. Принимает архивы клиентов с фото ID-карты
иностранца (외국인등록증) и банковской книжки, распознает данные, собирает документы
в Master-PDF, выгружает Excel-реестр и ZIP-архивы, печатает пакет «Договор + ID».

**Всё работает только на этом компьютере.** Никаких облачных сервисов: OCR, PDF,
база данных и файлы обрабатываются локально. Интернет нужен один раз — при установке.

## Как работает

**Шаг 1 — Импорт и реестр**
1. Выберите месяц (переключатель `‹ 2026-08 ›`) и перетащите архивы `.zip` / `.rar`.
   Один архив = один клиент: фото лицевой стороны ID, оборота ID и 통장사본.
2. Программа сама определяет, где какое фото, и распознает:
   - лицо ID: ФИО, номер ARC, дата рождения (YYMMDD), гражданство (англ.);
   - оборот ID: адрес регистрации (체류지) — последний; если он не читается, любой распознанный;
   - 통장사본: банк и счет — только в профиль клиента.
3. Экран «Приемка архивов» показывает каждый файл и как определен его тип. Нераспознанное
   фото подсвечивается — тип выбирается вручную, кнопка «Перечитать данные» распознает заново.
4. «Экспорт реестра (ID + Адрес)» — Excel: №, ФИО (заглавными), ФИО (строчными), Номер ARC, Дата рождения,
   Гражданство, Адрес регистрации. **Банковские данные не выгружаются.**

**Шаг 2 — Документы клиента**
1. Договоры, страховки, справки перетаскиваются в карточку клиента. Тип определяется по маске
   имени файла, затем по словам OCR (список типов ведете вы в «Типы документов»).
2. PDF с паролем открывается автоматически датой рождения (`YYMMDD`, `YYYYMMDD`) и вариантами номера ARC.
   Тип файла определяется по содержимому — файлы с сайтов без расширения `.pdf` тоже подходят.
   Если не подошло — в карточке появится поле для ручного ввода. В архивы попадают PDF без пароля.
3. Редактор скана (нажмите на фото ID): 4 угла, фильтр «Контраст» / «Чистый скан», лист А4 —
   лицо ID растянуто на всю ширину листа по центру.
4. «Собрать Master-PDF» — документы по очереди из «Типов документов»; отсутствующие пропускаются.
5. «Экспорт ZIP» — по каждому клиенту, все файлы без папок: документы (PDF без пароля), фото ID и 통장, Master-PDF. Договора и листа ID на А4 в ZIP нет — они внутри Master-PDF.

**Шаг 3 — Печать отчетности**
Отметьте клиентов (или «Выбрать всех») → «Печать отчетности»: `[Договор 1] ➔ [ID 1 на А4] ➔
[Договор 2] ➔ [ID 2 на А4] …` на принтер или в файл `BATCH_PRINT_<период>.pdf`. Если у
отмеченного клиента нет договора, программа предупредит — снимите с него галочку.

При каждом экспорте программа спрашивает, куда сохранить файл.

**Передача клиентов другому сотруднику** (без сети и общих папок): отметьте клиентов галочками на
дашборде → «Передать клиентов…» → файл `.e9pay` (пароль по желанию). Коллега перетаскивает файл в
окно своей E9pay или нажимает «Принять клиентов…» — данные и документы появляются без повторного OCR.
Недостающие типы документов добавляются автоматически.

**Телефон и e-mail:** поля в карточке клиента. «Экспорт реестра» выгружает их в Excel; заполните
недостающие и загрузите файл обратно кнопкой «Импорт реестра» — программа сама найдет клиентов по
номеру ARC (или по ФИО) и запишет телефон и почту, даже если все записано в одной ячейке.
Если в колонке «Адрес регистрации» адрес исправлен — он заменит адрес в карточке клиента.

**Расширение Chrome для сайта KICA:** в меню слева «🧩 Расширение Chrome» — инструкция по установке
(chrome://extensions → режим разработчика → «Загрузить распакованное» → папка `extension`). На странице
заявки нажмите значок E9pay и выберите клиента: заполнятся 이름 (строчными), 주민등록번호, 발급용 임시번호
(по умолчанию 112233, меняется в том же окне), телефон, 출신 국가, 주소, e-mail. Расширение получает данные
только у запущенной E9pay через 127.0.0.1 (этот компьютер) и отвечает только себе — в интернет данные
не уходят, кроме самой формы, которую вы заполняете.

**Обучение OCR** (меню «◎ Обучение OCR»): перетащите много фото ID-карт (лицо и оборот вперемешку) —
программа прочитает каждую, вы сверяете с фото и подтверждаете «Верно ✓» (Enter). Клиенты не создаются,
учебная база лежит только в `E9pass\training`. Проверенные ФИО сразу пополняют словарь имен (исправляет
похожие ошибки при приемке). Кнопка «Обучить модель…» один раз скачивает инструменты (PaddlePaddle +
PaddleOCR, ~2 ГБ, в `E9pass\training\toolkit`), затем дообучает модели распознавания на ваших картах
офлайн на обычном процессоре. Каждая пятая карта откладывается для проверки; новая модель подключается,
только если стала точнее, прежнюю можно вернуть.

**Повторы:** клиент с тем же номером ARC, добавленный меньше года назад (в любом месяце), не
принимается — программа показывает, где и когда он уже есть, и предлагает удалить прежнюю запись и
принять заново. Если прошел год и больше — клиент принимается как новый.

## Установка (Windows, один раз)

1. Установите **Python 3.12** с [python.org](https://www.python.org/downloads/windows/),
   отметьте **«Add python.exe to PATH»**.
2. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
3. Запустите **`setup.bat`** (несколько минут, около 500 МБ).
4. Дальше программа запускается через **`run.bat`**.

Данные хранятся в папке **`D:\E9pass`** (если диска D нет — `C:\Users\<вы>\E9pass`):
база `e9pass.sqlite3` и папки `periods\<месяц>\<клиент>\`. Другую папку можно задать
переменной окружения `E9PASS_HOME`.

**RAR-архивы** (RAR4, RAR5, solid) распаковываются 7-Zip из папки `tools` — он входит в установщик.
Дальше по очереди пробуются `tools\UnRAR.exe`, установленный 7-Zip и встроенный в Windows `tar.exe`.

**Установщик .exe** собирается в GitHub Actions только вручную: Actions → «Build Windows installer» →
Run workflow. Готовый файл появляется в Releases → `latest-build`. Локально: `build_exe.bat`.

## Проверка на вымышленных данных

```
.venv\Scripts\python tools\make_samples.py C:\Windows\Fonts\malgun.ttf samples
```
Создаст `samples\archives\*.zip` (фото лица, оборота, книжки) и `samples\later\…` (договоры,
в т.ч. с паролем = дата рождения). Настоящие документы клиентов никуда не отправляйте.

## Для разработчика

```
e9pass/db.py            SQLite: clients, client_documents, doc_rules
e9pass/services.py      приемка архивов, догрузка, пароли, Master-PDF, экспорт, план печати
e9pass/archive.py       распаковка zip/rar (имена cp949, защита от ../)
e9pass/pdf_tools.py     pikepdf (пароли), PyMuPDF (текст, склейка)
e9pass/scan.py          perspective crop, фильтры, лист А4
e9pass/ocr/             RapidOCR (PaddleOCR, ONNX) + разбор: front.py (лицо), back.py (адрес), bank.py, detect.py
e9pass/ui/              PySide6: dashboard, intake, client, doctypes, printing, scan_editor
tests/                  python -m pytest
```
