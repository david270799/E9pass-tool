# E9pass-tool — OCR ID-карт иностранцев → Excel

Программа для Windows: распознаёт лицевую сторону **외국인등록증** (ID-карты
иностранца в Корее) по фото с телефона или скану и сохраняет данные в Excel.

**Всё работает локально.** Изображения и данные не отправляются в интернет.
Интернет нужен только один раз при установке, чтобы скачать библиотеки и модель
распознавания. После этого программа работает офлайн.

## Какие поля извлекаются

| Поле в Excel | На карте |
|---|---|
| Рег. номер | 외국인등록번호 (`000000-0000000`) |
| ФИО | 성명 (латиница) |
| Страна / Страна (рус.) | 국가/지역 |
| Пол | 성별, либо по 7-й цифре номера |
| Дата рождения | вычисляется из номера |
| Виза / Статус | 체류자격, напр. `E-9` / `비전문취업(E-9)` |
| Дата выдачи | 발급일자 |
| Орган выдачи | напр. `수원출입국·외국인사무소장` |
| Проверить | что не удалось найти или что выглядит подозрительно |

Строки, требующие проверки, подсвечиваются жёлтым в программе и в Excel.

## Установка (один раз)

1. Установите **Python 3.12** с [python.org](https://www.python.org/downloads/windows/).
   В установщике отметьте **«Add python.exe to PATH»**.
2. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
3. Запустите **`setup.bat`**. Установка занимает 5–15 минут и около 2 ГБ места.

## Работа

1. Запустите **`run.bat`**.
2. Нажмите «Добавить файлы…» или «Добавить папку…». Поддерживаются JPG, PNG,
   HEIC (фото с iPhone), BMP, TIFF и WEBP.
3. Нажмите **«▶ Распознать»**. Первая загрузка модели занимает до минуты,
   потом примерно 3–15 секунд на одну карту на обычном ПК.
4. Проверьте таблицу. Справа показаны фото и распознанный текст. Двойной щелчок
   по ячейке позволяет исправить значение.
5. Нажмите «Сохранить в Excel…».

Без окна, сразу всю папку:
`.venv\Scripts\python tools\batch_cli.py папка_с_фото результат.xlsx`

### Советы по фото

- Снимайте карту целиком, сверху, без бликов на ламинате.
- Наклон и поворот допустимы: программа сама находит карту на фото и пробует
  разные повороты.
- Фото с низким разрешением или размытое почти всегда даст строку «Проверить».

## Сборка .exe (по желанию)

Если на рабочих ПК нельзя ставить Python: после `setup.bat` запустите
`build_exe.bat`. Получится папка `dist\E9passOCR`. Копируйте её целиком
(около 1–1,5 ГБ) и запускайте `E9passOCR.exe`.

## Безопасность данных

- Программа не делает сетевых запросов, когда модели лежат в папке `models`.
- Готовые Excel-файлы содержат персональные данные. Храните их в защищённом
  месте и не коммитьте в git (`*.xlsx` уже в `.gitignore`).
- Для тестов используйте вымышленные карты:
  `python tools/make_sample_card.py C:\Windows\Fonts\malgun.ttf samples`

## Для разработчика

```
e9pass_ocr/parser.py        разбор текста карты (регулярные выражения, без OCR)
e9pass_ocr/ocr_engine.py    EasyOCR + подготовка изображения (обрезка карты, повороты)
e9pass_ocr/excel_export.py  запись .xlsx
e9pass_ocr/app.py           окно (tkinter)
tests/                      тесты парсера: python -m pytest
```
